# Offene Fragen

Eine Zeile je Frage. Offen: `- [ ]`, beantwortet: `- [x]`. Nennt die Frage eine Prozess- oder Bereichs-ID, zählt sie in der Übersicht für diesen Bereich.

**Adressat:** Eine offene Frage endet mit `(an <Rolle>)`, z. B. `(an Lagerleiterin)`. `discovery stand` gruppiert die offenen Fragen danach (Rollen alphabetisch, „ohne Adressat“ zuletzt); fehlt der Adressat, gibt `discovery pruefen` einen Hinweis (keine Warnung). Rollen statt Namen. Eine beantwortete Frage darf nach „→“ die Antwort tragen; sie zählt nicht als offen.
