## Regeln

- Eine Seite je Thema, relative Links, neue Seiten hier verlinken.
- Keine Geheimnisse; Zugangsdaten nur mit Namen der Variable nennen.
- Stand und Aufgaben gehören in die Roadmap, nicht ins Wiki.
